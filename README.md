# dsh-client-ui-seaglass

[English](README.en.md) | 简体中文

> **适配版本** · DSH `0.1.6-alpha.2` – `0.1.7-rc.2`（含 DSHD 桌面端 v0.3.2）· **更新日期** 2026-09-29 · 插件 v1.8.0

Seaglass 是专为 DeepSeek Harness (DSH) 打造的高自由度全局玻璃质感主题。将页面的对话区、输入框、侧边栏及弹出层渲染为灵动通透的磨砂玻璃形态，支持自由更换高清壁纸与动态视频背景，并内置强大的 WebGL 流体动力学模拟与纯正中国红粒子动力学引擎。开关即开即用，关闭即可瞬时 100% 还原原生界面，零侵入、不触碰 DSH 核心代码。

## 🌟 核心特性

### 1. 纯正中国红「粒子党徽」系统
- **粒子动力学引擎**：基于 Canvas 2D / 3D 数学模型打造，精准还原官方鲸鱼粒子的聚集、散射、呼吸起伏与鼠标三维排斥微晃。
- **高纯度中国红呈现**：采用专属定制的高亮中国红（`rgb(242, 20, 25)`），优化图层混合模式为 `normal`，不论在深色还是浅色背景下均色彩饱满、轮廓分明，彻底告别发灰模糊。
- **流体色彩联动**：开启粒子党徽模式后，底层的水下流体动力学 Shader 自动同步切换为庄严肃穆的中国红主题色调。

### 2. 生动灵巧的「动态小党徽」漂浮群落
- **多层景深与对称数量**：背景层内置 4 只不同层级、不同大小（18px ~ 34px）和周期的党徽剪影，分布密度与小鱼群落完全齐平。
- **平滑摇曳漂浮动画**：
  - 采用独家定制的 `@keyframes dsh-aqua-emblem-float` / `dsh-aqua-emblem-float-left` 补间动画；
  - 呈现 12s ~ 16s 四向平滑漂流与微倾摇曳；
  - 开启 `will-change: transform` GPU 硬件加速，配合柔和的红色微光投影（`drop-shadow`），飘动自然丝滑。

### 3. 双列网格现代化设置面板
- **对称双列排布**：采用严谨的 CSS Grid `1fr 1fr` 双列网格结构，按钮行高对齐、间距匀称：
  - **第 1 行**：左侧「粒子鲸鱼」 ｜ 右侧「粒子党徽」
  - **第 2 行**：左侧「动态小鱼」 ｜ 右侧「动态小党徽」
  - **第 3 行**：左侧「网状交互」
- **精致控件质感**：30px 统一规格圆角胶囊开关，启用时带柔和主题辉光；设置卡片支持高级微毛玻璃质感（`backdrop-filter: blur(10px)`）与悬停高亮边框。
- **纯中文原生体验**：全面修复词条与字符编码，中文字体选择器原生标识为「微软雅黑」，告别乱码。

### 4. 经典双模式与高自由度自定义
- **云母效果 (Mica)**：界面重构为悬浮微透玻璃卡片，支持光标悬停辉光与下压物理微动效；
- **兼容模式 (Compat)**：完全保持原生布局与尺寸，仅对底层材质赋予玻璃质感；
- **多维调节**：提供玻璃模糊度、磨砂度、代码块独立磨砂度、色调深度等无级平滑调节；
- **自由背景**：支持自定义高分辨率图片与视频壁纸，自动做微暗压光以确保文字清晰可读；
- **独立字体族**：可为西文字体与中文字体（CJK）分别配置系统字体族。

## 🚀 安装指南

### 方式一：npm 一键安装（推荐）

针对桌面端（Desktop）：
```sh
dsh plugin --profile desktop add dsh-client-ui-seaglass
```

针对 Web 端：
```sh
dsh plugin --profile web add dsh-client-ui-seaglass
```

### 方式二：本地仓库安装（二次开发 / 调试）

克隆仓库后，本地构建并直接装入对应 profile：

```sh
# 1. 克隆代码仓库
git clone https://github.com/MeYangGe/dsh-client-ui-seaglass.git

# 2. 进入目录并安装依赖
cd dsh-client-ui-seaglass
pnpm install

# 3. 编译打包客户端与主进程产物
pnpm run bundle

# 4. 安装进桌面端 Profile（请填入本地实际绝对路径）
dsh plugin --profile desktop add "C:\path\to\dsh-client-ui-seaglass"
```

## ⚙️ 设置面板速查

在客户端进入 **设置 -> Seaglass 主题**，可进行如下配置：

| 设置分组 | 功能项 | 默认值 | 功能说明 |
| :--- | :--- | :---: | :--- |
| **基础模式** | 云母效果 / 兼容模式 | 云母效果 | 切换悬浮卡片立体风格或平铺原生风格 |
| **玻璃材质** | 玻璃模糊度 (px) | 16px | 调节卡片背后的高斯模糊半径（0 ~ 40px） |
| | 磨砂度 (%) | 50% | 调节玻璃透光度与磨砂厚重感 |
| | 代码块磨砂度 (%) | 50% | 独立调节代码区域的磨砂度，确保代码高亮清晰 |
| **背景配置** | 流体 / 壁纸 | 流体 | 切换 WebGL 流体模拟或自定义图片/视频背景 |
| | 色调 / 颜色深浅 | 默认 | 调节流体主色与色彩饱和层级 |
| | 选择图片 / 视频 | - | 导入本地高分辨率图片或动态 MP4 视频 |
| **环境装饰** | **粒子鲸鱼** | 开启 | 居中展示官方 3D 动力学粒子鲸鱼 |
| *(双列网格)* | **粒子党徽** | 关闭 | 居中展示纯正中国红粒子党徽，流体同步转红 |
| | **动态小鱼** | 开启 | 水下自由穿梭的深海游鱼剪影 |
| | **动态小党徽** | 关闭 | 水下 4 只微倾摇曳、平滑飘浮的中国红发光微章 |
| | **网状交互** | 开启 | 粒子点阵跟随鼠标牵引波动 |
| **悬停动效** | 鼠标辉光 / 悬停下压 | 开启 | 鼠标划过卡片时的聚光灯光晕与点击物理反馈 |
| **字体设定** | 英文字体 / 中文字体 | 默认 | 独立指定西文和中文字体（默认中文字体为微软雅黑） |

## 💡 常见问题与说明

1. **修改或替换插件文件后如何立即生效？**
   由于客户端内存缓存机制，更新插件代码后，在 DeepSeek Harness 客户端窗口内按下 **`Ctrl + R`**（或 `Ctrl + Shift + R` / `F5`）刷新界面即可载入最新样式与脚本。
2. **粒子党徽与动态小党徽如何独立控制？**
   两者采用独立的本地持久化存储键：
   - 粒子党徽控制正中央的 3D 散射粒子图形与中国红流体 Shader；
   - 动态小党徽控制水下飘浮的 4 只微章剪影，两者可自由组合开启或关闭。
3. **如何彻底恢复原生界面？**
   在设置面板顶部关闭 Seaglass 主开关，或者卸载插件，界面将在 0 毫秒内完全恢复为原生深色/浅色样式，不留下任何残留。
