# dsh-client-ui-seaglass

[English](README.en.md) | 简体中文

> **适配版本** · DSH `0.1.6-alpha.2` – `0.1.7-rc.2`（含 DSHD 桌面端 v0.3.2）· **更新日期** 2026-09-29 · 插件 v1.8.0

Seaglass 是一个高自由度的玻璃质感主题。将页面各功能区渲染为通透的磨砂玻璃片，支持自定义图片与视频作为背景。关闭开关即可完全回到原生界面，不修改 DSH 任何一行核心源码。

## 特性

- **双模式切换**：
  - **云母效果**：将界面重构为悬浮玻璃卡片布局，通透灵动；
  - **兼容模式**：保持原生排版布局，仅替换底层材质为玻璃质感。
- **动态中心粒子装饰**：
  - **粒子鲸鱼**：官方同款 3D 散射与游动粒子效果；
  - **粒子党徽**：纯正中国红粒子动力学中心标识，跟随鼠标立体微晃与聚集散射。
- **环境游动剪影**：
  - **动态小鱼**：水下鱼群自由穿梭游动；
  - **动态小党徽**：4 只多层级、双向微倾漂浮的中国红发光微章剪影。
- **中国红流体背景联动**：开启党徽模式后，水下流体自动切换为中国红主题色调。
- **双列网格现代化设置面板**：整齐对称的开关排布，支持独立持久化存储。
- **自由背景支持**：支持自定义高分辨率图片与动态视频背景（自动微暗压光与磨砂模糊）。
- **中 / 英文独立字体自定义**：可为西文与中文字体分别配置系统字体族。
- **一键开关**：关闭即瞬间 100% 还原原生界面，零侵入性。

## 安装

### 方式一：npm 一键安装（推荐）

```sh
dsh plugin --profile desktop add dsh-client-ui-seaglass
```

或针对 Web 端：

```sh
dsh plugin --profile web add dsh-client-ui-seaglass
```

从 npm 安装最新版，自动注册为 profile 插件层（`dsh.bundle` 补丁），所有平台通用。刷新页面即可。

### 方式二：本地仓库安装（调试 / 二次开发）

克隆到本地后，使用 `dsh plugin add` 直接将本地文件夹装入 profile：

```sh
git clone https://github.com/MeYangGe/dsh-client-ui-seaglass.git
pnpm install
pnpm run bundle
dsh plugin --profile desktop add "C:\path\to\dsh-client-ui-seaglass"
```

## 设置项说明

在 **设置 -> Seaglass 主题** 中，提供以下精细化控制面板：

| 分组 | 控制项 | 说明 |
| :--- | :--- | :--- |
| **基础模式** | 云母效果 / 兼容模式 | 选择悬浮卡片式或平铺兼容式玻璃外观 |
| **玻璃材质** | 模糊度 / 磨砂度 / 代码块磨砂度 | 无极调节卡片的高斯模糊半径与透光磨砂质感 |
| **背景配置** | 流体 / 壁纸 | 选择实时流体动力学模拟或自定义图文/视频壁纸 |
| **环境装饰** | **粒子鲸鱼** / **粒子党徽** | 界面正中央的主题粒子标识切换，中国红高亮渲染 |
| | **动态小鱼** / **动态小党徽** | 背景中自由穿梭游动的环境微章剪影，数量齐平对称 |
| | **网状交互** | 界面网格点阵跟随鼠标牵引波动 |
| **悬停效果** | 鼠标辉光 / 悬停下压 | 鼠标在玻璃卡片上移动时的聚光灯光晕与点击物理反馈 |
| **字体设定** | 英文字体 / 中文字体 | 独立指定拉丁字元与 CJK 字符渲染字体族 |
